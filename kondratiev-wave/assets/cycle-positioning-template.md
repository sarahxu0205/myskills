# 周期定位工作表模板

> 用于把康波/库存周期判断落到一张可复用的工作表上。按「判断 → 指标 → 结论」三步填写。

## 第一步：康波阶段判断

| 阶段 | 判断指标 | 是否吻合 |
|------|----------|----------|
| 回升 | 新技术导入、全要素生产率抬升 | ☐ |
| 繁荣 | 投资与信用扩张、资产全面繁荣、产能利用率高位 | ☐ |
| 衰退 | 增长回落、资源约束+信用膨胀、标志性危机出现 | ☐ |
| 萧条 | 去产能去杠杆、通缩、价格见底 | ☐ |

- 主导周期（长波/中波/短波）判定：____________________
