# 人生财富靠康波 - 方法论 Skill

> 基于 周金涛 的《人生财富靠康波》
>
> 本 Skill 仅供个人学习使用

## 核心目的

帮助投资者和普通人认识"康波周期"（约 60 年的经济长波）这一决定人生财富的根本力量，学会判断当前所处周期阶段，并据此进行大类资产配置和人生财富择时，从而在资产价格的低点买入、高点兑现，实现财富的保值与增值。

**核心收益：**
- 建立"康波四阶段 + 三/四周期嵌套"的周期定位框架
- 掌握大类资产（商品/房地产/股票/黄金/现金/债券）的轮动规律
- 学会用"增长-通胀关系、美元周期、房地产周期"做资产配置
- 获得"人生发财靠康波"的长期择时人生规划观

## 适用场景

✅ **推荐使用：**
- 判断当前宏观经济与资产价格所处的周期阶段（宏观择时）
- 做大类资产配置（股票/债券/商品/黄金/现金之间的轮动）
- 房地产买卖时点判断（识别牛熊周期与 B 浪反弹）
- 黄金等贵金属的长期战略配置时点选择
- 个人长期财富规划与人生关键财务决策

❌ **不推荐使用：**
- 短期日内交易或高频波段择时（康波是长周期，不解决短期噪音）
- 个股基本面选股（本书聚焦大类资产而非个券）
- 无法获取宏观与价格数据、完全不懂投资术语的场景

## 快速上手

> 一句话概括：先判断当前处于康波周期的哪个阶段，再据此做大类资产配置，在低点买入、高点兑现。

**最简使用流程：**
1. **定位康波阶段** —— 判断回升/繁荣/衰退/萧条，及衰退中的一次/二次冲击位置
2. **嵌套周期校准** —— 用三/四周期嵌套细化中短周期位置
3. **判断增长通胀组合** —— 用"增长-通胀四象限"确定资产轮动方向
4. **叠加美元与房地产周期** —— 升级为跨市场、跨资产配置框架
5. **执行配置与兑现纪律** —— 保值优先、流动性优先，在低点买、高点卖

**核心原则速记：**
- 人生发财靠康波，财富积累源于周期给予的机会，而非个人能力
- 赚钱不重要，第一目标是保值，第二目标是流动性
- 判断资产配置前，先判断当前处于周期的哪个阶段

## 核心工作流程

> 完整方法论按需加载：理论见 `references/kondratiev-wave-theory.md`，嵌套见 `references/cycle-nesting.md`，资产配置见 `references/asset-allocation-framework.md`，实战判断见 `references/practical-playbook.md`。

### 阶段 1：定位康波阶段

判断当前处于回升 / 繁荣 / 衰退 / 萧条的哪一段，以及衰退中的一次 / 二次冲击位置。

- 用全要素生产率、产能利用率的高点定位繁荣顶点
- 用标志性危机（如 2008 年次贷、布雷顿森林体系崩溃）确认衰退起点
- 用商品 10 年大牛市 + 之后约 20 年熊市（前 7 年主跌段）判断衰退与萧条的转换节奏

**依赖关系：** 无

### 阶段 2：嵌套周期校准

用三/四周期嵌套细化当前所处的中短周期位置。

- 记住嵌套关系：康波 60 年 ⊃ 2 个房地产周期 ⊃ 6 个中周期 ⊃ 18 个库存周期
- 判断当前处于第几库存周期（第一 / 二 / 三库存周期）
- 用库存周期低点与中周期低点交叉定位终极低点

**依赖关系：** 定位康波阶段

### 阶段 3：判断增长通胀组合

用增长与通胀的方向组合确定大类资产轮动象限（美林投资时钟改造版）。

- 复苏（增长升、通胀降）→ 超配股票
- 过热（增长升、通胀升）→ 超配商品
- 滞胀（增长降、通胀升）→ 现金与黄金
- 衰退（增长降、通胀降）→ 超配债券

**依赖关系：** 定位康波阶段

### 阶段 4：叠加美元与房地产周期

加入汇率与房地产周期，把美林时钟升级为跨市场配置框架。

- 用"美强欧弱"判断美元牛熊（美元周期由房地产周期驱动）
- 识别房地产周期约 25～30 年轮回（上行约 8.5 年、下行约 17 年）与国别传递（主导国 → 外围主导国 → 追赶国 → 附属经济体、资源国）
- 识别熊市中的 B 浪反弹，作为"兑现"而非"加仓"的时点

**依赖关系：** 嵌套周期校准

### 阶段 5：执行配置与兑现纪律

把周期判断落地为买卖动作，并守住风险纪律。

- 保值优先于增值、流动性优先于收益
- 在周期低点买入资产、高点卖出
- 以 CPI / PPI 为指针：涨得动就持有，掉头就抛资产、留现金与黄金
- 一生只有 3 次大机会，只在不确定但高赔率时下注

**依赖关系：** 判断增长通胀组合

## 核心原则

- **人生发财靠康波**：财富积累源于周期给予的机会，而非个人能力
- **保值优先、流动性优先**：赚钱不重要，第一目标是保值，第二目标是流动性
- **先定位周期、再配置资产**：判断资产配置前，先判断当前处于周期的哪个阶段
- **必须回溯 50 年**：10 年前的经验对后 10 年没有任何借鉴意义
- **低点买进才有意义**：任何机会都是赌出来的，等一切都确定时机会已经不属于你；错过了低点买进就没有意义

## 注意事项与警告

- ⚠️ 不要用"央行放水就会涨"的过去 6 年思维判断未来（2015 年之后放水不管用了）
- ⚠️ 2016—2017 年一线城市核心区房价是 B 浪反弹，投资性房产应卖出而非追买
- ⚠️ 新三板等一级市场股权流动性极差，是"消灭中产财富"的陷阱，不要追逐
- ⚠️ 2016 年之后即使大宗商品是熊市也不能做空（价格已跌出安全边际）
- ⚠️ 把已经"无孔不入"的成熟技术（如互联网+）当新风口追逐，是认知陷阱

**避坑指南：**
- 每年开年前先想清楚这一年的投资主逻辑（如 2016 年 = 脱虚向实"炒涨价"）
- 用 CPI / PPI 做指针：涨得动就正常持股/持商品，有掉头趋势就抛资产留现金 + 黄金
- 资源国资产（澳元、澳房）要等到资源最低点（约 2018—2019 年）再买
- 建立"现金为王"的安全垫，为 2018—2019 年的流动性危机做好准备

## 输出规范

### 标准输出结构

1. **周期定位**：当前康波阶段 + 第几库存周期 + 所处增长-通胀象限
2. **配置建议**：对应的大类资产方向（做多 / 做空 / 中性）
3. **兑现 / 止损边界**：CPI/PPI 掉头、美元破位、B 浪识别等拐点信号

输出时按需附：四周期嵌套图、资产轮动对照表（模板见 `assets/`）。

### 前置准备

**知识**：基本的宏观经济学概念（GDP 增长、通胀 CPI/PPI、利率、汇率）；康波 / 朱格拉 / 基钦 / 库兹涅茨四周期嵌套概念；美林投资时钟四阶段。

**工具**：宏观数据库（Wind、CEIC、DATASTREAM 等）或公开数据源；CPI/PPI、美元指数、CRB 商品指数、房价指数、金价等价格序列；美国实际利率（10 年期美债收益率减通胀）等指标。

**环境**：能跟踪美国、欧洲、中国的经济周期节奏；关注美元指数与全球房地产周期信号。

## 触发条件与使用说明

### 触发条件

当用户出现以下情况时触发此 Skill：
- 用户提到"康波 / 康波周期 / 康德拉季耶夫 / 经济周期 / 长周期 / 人生发财靠康波"
- 用户询问"现在该买什么资产、该买还是卖房、黄金能否买"
- 用户在做宏观择时或大类资产配置决策

### 输入参数

- 当前关注的时间维度（长周期择时 vs 年度配置）
- 想配置的资产类别（股票 / 债券 / 商品 / 黄金 / 房地产 / 现金）
- 已掌握的宏观数据与所处市场（中国 / 美国 / 欧洲）

### 输出格式

输出当前康波/库存周期定位、增长-通胀象限、对应的资产配置建议与兑现/止损边界，必要时附四周期嵌套图与资产轮动对照表。
