# 实战打法与判断手册

> 本文件详述周期定位指标、B 浪/二次冲击识别、一波三折反弹节奏、结构主义视角、工业化与主导产业更替、共生模式与资源品、长波衰退中的增长-通胀转化，以及关键提问与检验清单。
> 供 SKILL.md 阶段 1、5 及避坑时按需加载。

## 1. 周期定位指标

把"道"（康波阶段）落到"术"（可观测指标）：

| 指标 | 判断什么 |
|------|----------|
| 全要素生产率（技术进步） | 康波繁荣顶点的先导；生产率波动先于价格/增长见顶 |
| 产能利用率 | 繁荣顶点与库存周期位置的确认 |
| 标志性危机 | 衰退/萧条的起点确认（2008 次贷、布雷顿森林体系崩溃、2011 商品双头） |
| CPI / PPI | 涨得动=持有资产；掉头=抛资产留现金+黄金 |
| 实际利率（美债收益率-通胀） | 黄金与美元信用对冲的判断 |
| 美元指数 | 美元牛熊、新兴市场风险的领先信号 |

## 2. 康波衰退"双冲击"定位

衰退不是一步到位，而是以两次冲击的方式进入萧条：
- **一次冲击**：宣告衰退开始（第五次康波 = 2008 年次贷危机）。
- **二次冲击**：深度探底、触发向萧条转换（如 2014—2015 年商品二次探底、资源国危机）。

用两次标志性危机框定衰退的进入方式与向萧条的转换节奏，是判断"现在离底部还有多远"的关键。

**补充定位规则**：衰退→萧条的转换点应定位在**中周期低点**上（本次约 2018 年）；终极低点之前通常先出现一次探底（如 2015Q4—2016H1），随后进入"超跌反弹"。这一"探底+反弹"在商品周期里对应**涛动周期**（见 `references/asset-allocation-framework.md` 的四周期嵌套）。

## 2.1 四周期共振与终极低点定位

- **四周期共振**：周金涛明确判断"2007 年是四周期共振高点，2018 年或 2019 年将出现四周期共振低点"。这是全书对周期大拐点级别的最强定位——高点/低点均由四个周期力量同向共振决定。
- **三期共振低点**：2018 年的"三期共振低点"才是商品价格的真正长期低点（原书对"三期"未展开逐一命名，只作定位术语引用，不自行拆解其组成）。
- 与既有"衰退→萧条转换点=中周期低点（约 2018）""库存周期低点×中周期低点交叉"相互印证，共同框定终极低点约在 2018—2019 年。

## 3. B 浪反弹识别

- 在房地产/商品熊市中出现的反弹，通常由**中周期上行**解释，本质是"熊市中的 B 浪反弹"，是**兑现机会而非加仓机会**。
- 判别心法：反弹缺乏"系统性需求"支撑，仅表现为中周期修复 → 卖出而非追买。
- 典型：2016—2017 年一线城市核心区房价、2016 年商品第三库存周期反弹，都应视为 B 浪，投资性仓位应择机兑现。

## 4. 一波三折：第三库存周期的反弹节奏（补全）

> 来源：《一波三折——周期反弹节奏研究》。第三库存周期中大宗商品的反弹不是单边拉升，而是呈"一波三折"的节奏结构。

- **形态**：一次触底 → 一次反弹 → 一次触顶 → 回落 → 第二次触底 → 主升浪 → 第二次触顶（"一波三折"）。
- **关键量（过去 6 个第三库存周期的统计）**：第三库存周期所有品种平均涨幅约 163%（主升浪约 157%、第一次反弹约 54%、一次触顶到二次触底的回落约 38%）；反弹平均时长约 19 个月（第一次反弹约 4 个月、调整 3～5 个月、主升浪最短 10 个月）。
- **第三库存周期 = 滞胀**：经济触底时通胀速度快于经济上行，触顶后通胀还能再上行两个季度；滞胀阶段大宗商品是各类资产里收益率最高的资产。
- **中美共振 = 主升浪**：中国领先开启第三库存周期是第一波，中美第三库存周期共振才是商品主升浪。领先触顶顺序大致为：糖 → 铁矿 → 石油 → 铅 → 黄金（糖最先、金属里铅最先），回落较晚的是石油和铝。
- **操作心法**：反弹缺乏"真实需求"支撑、是下降大趋势里的反弹；第一波没参与不重要，调整反而检验周期信仰，是判断能否"买进"的时点。

## 5. 结构主义视角（补全）

> 来源：《结构主义的薪火》篇 + 推荐序一。这是全书最深层的分析视角，原 SKILL 未提炼。

- **核心命题**：周期是「经济 + 技术 + 社会系统 + 制度变革」的综合产物；宏观指标只是周期大系统的表面现象。
- **两条主线**：**周期波动**与**结构演进**。策略研究（趋势 + 配置）以这两条主线的交会来完成。
- **总量逻辑的失效**：长波衰退期（如 2010 年大拐点后的未来 20 年），全球增长总量边际递减不可抗拒，依据总量的投资逻辑只能抓到反弹波段；机会存在于**结构变动**而非总量变化中。
- **结构与制度归宿**：结构主义最终归宿是"制度"。经济趋缓时财富分配凸显，分利集团膨胀抑制创新，必须进行实质性的制度变革（打破"制度刚性"）。
- **两个级别的结构变动**：
  1. 大级别结构变动（经济特征的结构变迁，如工业化起飞→成熟）；
  2. 周期中的结构变动（每个周期内的行业此消彼长）。
  对中国（工业化进程中的发展中国家）而言，**结构变化的权重高于周期波动**（"大结构、小周期"）；对成熟经济体（美国）则相反（"大周期、小结构"）。
- **投资含义**：从"结构线索"中寻找成长机会，新老主导产业辩证看（老产业可升级重生，新兴产业也非必然）。

## 6. 工业化与主导产业更替（补全）

> 来源：《繁荣的起点》《走向成熟》篇（罗斯托经济增长阶段理论）。

- **罗斯托阶段**：工业化起飞（约 20 年，固定资产投资剧烈膨胀）→ 走向成熟（结构升级、财富分配凸显）→ 大众消费时代。
- **主导产业更替**：主导部门更迭"不会是突发的"，与旧主导部门保持联系；新主导部门的确定取决于技术条件、资源禀赋、起飞阶段的性质与发动力。
- **三/四次康波的主导产业**：纺织 → 铁路钢铁 → 电气化工 → 汽车计算机 → 信息技术。
- **走向成熟阶段的五大变化（寻找成长的线索）**：
  1. 投资拉动仍持续，但投资结构实质性变化；
  2. 生产能力规模化、资本集中、经济大型化（中游偏上产业）；
  3. 新老主导产业交替、社会分工深化、中游膨胀、**装备制造业繁荣**；
  4. 城市化与工业化加速、区域差异达到顶峰后扩散；
  5. 收入分配不均达到高峰、分配改革实质推进、消费多样化。
- **投资结构演进逻辑**：投资品 → 半投资品 → 半消费品 → 消费品；投资重点由"中游上端"向"中游下端 / 下游"转移，装备制造业（自动化装备、高级机床、工程机械、交通运输设备等）与新消费产业（互联网/IT/电信增值/医疗教育/传媒）受益。
- **刘易斯拐点**：劳动力供应逆转、工资刚性上升 → 资本收益率中期下降、通胀中枢上移、贫富分化与社会矛盾，"通胀中期化"。

## 7. 共生模式与资源品价格（补全）

> 来源：《色即是空》篇——世界经济的共生模式与国际资源品价格调节新机制。

- **供需是价格的根本**：资源品价格是其供给与实体经济增长需求博弈的结果；大牛市一定在资源供需矛盾"极度冲突"时产生。
- **大牛市的形成条件**：世界经济**长周期的衰退**（导致资源供给能力持续衰弱）+ **中周期的强劲复苏**（导致需求迅速增加）共振，即 20 年代、70 年代及 2000s 三轮资源大牛市的共同背景。
- **传统调节机制 = 滞胀**（封闭经济）：资源涨价 → 通胀 → 需求减弱 → 资源行业投资增加 → 供需再平衡。前提是消费者与生产者同一环境、资源与非资源行业在同一国家利益下博弈。
- **新的调节机制 = 共生模式**（开放经济）：国际分工纵向一体化，世界经济增长形成"共生模式"；美元贬值对资源品的影响不止于标价，更关系共生模式的稳定或瓦解；"中国因素/金砖四国"不再是支离破碎的利多，而应纳入世界产业分工链条理解。
- **判断逻辑**：判断大宗商品，对世界经济**中周期与长周期**的分析都不可或缺；商品价格达到上升周期中后期后，供需缺口弥合 + 流动性收缩将侵蚀牛市根基，是价格波动加剧、风险凸显时期。

## 8. 长波衰退中的增长-通胀转化（补全）

> 来源：《长波衰退中的增长与通胀》篇。

- **分辨"美元企稳是长期还是短期现象"、油价新高是"标价还是供需"**，本质是同一问题：长波衰退中币值变动 + 通胀使增长趋势复杂化。
- **第四次康波（1948—1991）的增长-核心 CPI 博弈**：
  1. 1948—1966：技术创新带动生产率提升，增长 > 通胀；
  2. 1966—1973：资源需求上升、供给有限，核心 CPI 逐渐超越增长；
  3. 1973—1982：成本推动型通胀主导，生产率提升放缓，只能靠经济增长大幅减速降成本；
  4. 1982—1991：新技术赋予复苏动力 + 资源重归平衡。
- **美元本位的放大机制**：美元本位缺乏金本位下黄金流动对贸易失衡的抑制，美国赤字政策 + 美元储备膨胀 → 需求被放大、信用催生产能过剩；资源约束**更多向通胀与资产泡沫化演化**。这就是美元体系下通胀治理艰难、资产泡沫频发的原因。
- **资源约束 + 产能过剩**是长波衰退的两个基本原因；增长与通胀的博弈决定了衰退期的运行方式。

## 9. 关键提问清单

1. 当前处于康波（回升/繁荣/衰退/萧条）的哪个阶段？
2. 现在是第几库存周期？价格触底或见顶了吗？
3. CPI 与 PPI 是"涨得动"还是"要掉头"？
4. 美元处于牛市还是熊市？由谁的房地产周期决定？
5. 这项资产的流动性如何？能在下行期顺利变现吗？

**反思三问（人生规划视角）：**
- 以我的出生年代算，一生还有几次周期机会？错过这次下次在何时？
- 我持有的资产是"保值"还是"冒险"？收益与流动性哪个优先？
- 我是在价格上涨时才想买，还是在低点提前布局？

## 10. 检验清单（自测）

- [ ] 康波阶段定位是否有标志性危机（如 2008/2011 年商品双头）支撑？
- [ ] 当前处于第几库存周期？价格是否已触底？
- [ ] CPI / PPI 是否转头？对应资产是否切换（商品/黄金/现金）？
- [ ] 美元牛熊是否与全球房地产周期（美强欧弱 / 东升西弱）一致？
- [ ] 配置是否满足"保值优先、流动性优先"？
- [ ] 是否把成熟技术当新风口、把 B 浪反弹当新牛市追买？
- [ ] 周期位置判断是否至少有两个独立指标相互印证？
- [ ] 每个结论是否都给出了兑现/止损边界（如 CPI/PPI 掉头、美元破位）？

## 核心结论速览

1. 定位指标：全要素生产率 + 产能利用率 + 标志性危机 + CPI/PPI + 实际利率 + 美元指数。
2. 康波衰退以"双冲击"进入萧条；衰退→萧条转换点=中周期低点（约 2018）；熊市反弹多为 B 浪，应兑现而非加仓。
3. 第三库存周期反弹"一波三折"：触底→反弹→触顶→回落→二次触底→主升浪→二次触顶（平均涨幅约 163%）。
4. 结构主义：周期 = 经济/技术/社会/制度的综合，结构变动权重高于总量。
5. 工业化：罗斯托阶段 + 主导产业更替 + 走向成熟五大变化 + 刘易斯拐点。
6. 资源品：长周期衰退 + 中周期复苏共振成就大牛市；共生模式取代滞胀成为新调节机制。
7. 长波衰退：资源约束 + 产能过剩是两大基本原因，美元本位放大通胀与资产泡沫。
