# SCAMPER 输出模板

三档模板按 `SKILL.md` 第十三节选择。默认标准档；用户说"快速/简单说"走速览；说"详细/完整"走深度。

---

## 一、速览档（≤600 字）

```markdown
**对象**：<X> ｜ **痛点**：<Y> ｜ **约束**：<Z>
**主攻维度**：<2-3 个>（其余维度已扫，各保留 1 条）

**关键假设**：<1 条最关键>（推断）——若不准，Top3 会变。

**创意**
1. `S1 <因果链一句话>`（层次｜级别）
2. `C1 <因果链一句话>`（层次｜级别）
3. `A1 <因果链一句话>`（层次｜级别）
4. `M1 <因果链一句话>`（层次｜级别）
5. `E1 <因果链一句话>`（层次｜级别）
6. `R1 <因果链一句话>`（层次｜级别）

**组合 X1**：<两条创意怎么拼，产生什么单一维度做不到的效果>

**Top3**：<方案 A>（<综合分>，优先做）｜<方案 B>（<综合分>，优化后做）｜<方案 C>（<综合分>，优化后做）

**缺口**：还缺 <缺什么> —— 补充后可重排 Top3 并给验证指标。
```

速览档不写：现状解构展开、评分依据表、方案卡、验证计划。

## 三、深度档（不限字数）

在标准档基础上，每个 Top3 方案追加：

```markdown
### 方案 <N>：<名称>

- **机制**：<这条创意为什么有效，依赖哪个用户假设>
- **目标用户与场景**：<谁、在什么场景、什么时候用>
- **边界**：<什么情况下会失效>
- **MVP（2-4 周）**：<最小可验证版本包含什么、不包含什么>
- **里程碑**：第 2 周 / 第 6 周 / 第 12 周分别交付什么
- **资源**：人力、预算、外部依赖
- **风险与应对**：<风险 → 对策>
- **证伪条件**：若 <时间窗> 内 <指标> 未达 <阈值>，则 <放弃/降级/转向>
```

并在末尾追加 90 天计划：

```markdown
## 90 天计划

| 阶段 | 时间 | 目标 | 关键动作 | 验收标准 |
|---|---|---|---|---|
| 验证 | 第 1-2 周 | | | |
| 试点 | 第 3-6 周 | | | |
| 放大 | 第 7-12 周 | | | |
```

## 四、HTML 报告（默认生成）

**默认规则**：每次正式分析都生成，无需用户要求。
**例外**：基础级追问阶段、用户明确只要文字、无法写文件（改为附代码块）。

**档位裁剪**

| 档位 | 保留模块 | 裁剪或替换 |
|---|---|---|
| 速览 | 头部、关键假设、七维创意列表、X1 组合、Top3 一行表、信息缺口 | 删除结论三条、现状解构、验证与下一步、90 天计划；七维卡片改为单列创意列表，跨维组合只保留 X1，Top3 改为一行表 |
| 标准 | 除 90 天计划外的全部模块 | 删除 90 天计划 |
| 深度 | 全部模块 | 不裁剪 |

速览版替换口径：头部 meta 增加「主攻维度」chip；七维卡片改为每维一行的列表（`S 替代：S1 <创意>；S2 <创意>`）；跨维组合只保留 X1；Top3 方案卡改为一行表（`排名 | 方案 | 综合分 | 决策`）。

**步骤**

1. 先完成 Markdown 分析，确认已过六条质量闸门。
2. 读取 `assets/report-template.html`，按档位裁剪并替换为真实数据。
3. 输出单文件 HTML：`<style>` 内联，无 CDN、外链字体、图片、脚本。
4. 保存为 `SCAMPER创新方案-<对象名>-<YYYYMMDD>.html`。
5. 自检后一次性回复：Markdown 分析 + 文件路径 + 一句话说明。

**模块映射**

| HTML 模块 | 对应 Markdown |
|---|---|
| 头部信息条 | 分析边界声明 |
| 结论三条 | 结论 |
| 关键假设 | 关键假设（待确认） |
| 现状解构 | 一、现状解构 |
| 七维卡片 | 二、七维分析 |
| 跨维组合 | 三、跨维度组合 |
| Top3 方案卡 | 四、Top3 方案卡 + 证伪条件 |
| 验证与下一步 | 五、验证与下一步 |
| 信息缺口 | 缺口说明与待核实项 |
| 90 天计划（仅深度） | 深度档的 90 天计划 |

**自检清单**

- [ ] 离线双击可打开，无外部请求
- [ ] 窗口缩到 375px 宽无横向滚动
- [ ] A4 打印不截断、不丢卡片
- [ ] 【推断】标记在 HTML 中保留
- [ ] 关键假设模块位于结论之后，底部只有信息缺口，无重复标题
- [ ] 档位裁剪正确：速览无现状/验证/90 天，且保留 1 条组合；标准无 90 天；深度全保留
- [ ] 文件名符合 `SCAMPER创新方案-<对象名>-<YYYYMMDD>.html`

**无法写文件时**：在回复末尾附完整 HTML 代码块，并说明可保存为 `.html` 打开；不得静默跳过。
