# SCAMPER 七维提问矩阵

## 一、使用说明

- 这是七维的**检核表**：先按维度扫一遍，再按 `SKILL.md` 的规则筛。
- 每条创意填写粒度：一句因果链 + 两个标签，不写长段落。
- 单条创意 ≤60 字；写不出机制的直接丢弃，不留"可能有用"。

## 二、标记约定

| 标记 | 取值 | 含义 |
|---|---|---|
| 层次 | 功能 / 流程 / 商业 | 功能=用户看到与操作的；流程=谁在何时做什么、怎么交接；商业=谁付费、谁分销、靠什么持续 |
| 级别 | 微调 / 改良 / 重构 | 微调=只改材料外观参数；改良=用户行为路径变；重构=价值交付方式或收入结构变 |
| 可行性 | 高 / 中 / 低 | 是否在现有资源与约束内可做 |

七维合计硬规则：至少覆盖 2 个层次，至少 1 条"商业"层，至少 1 条"重构"级。

## 三、对象类型 × 维度切入点

| 对象类型 | 高优先维度 | 切入问法 | 典型陷阱 |
|---|---|---|---|
| 实体/数字产品 | 替代、修改、删除 | 哪个部件/材料/技术/功能可以被替换、缩放或移除？删掉后用户会不会更爽？ | 只换颜色/文案/包装，判为微调 |
| 服务 | 适应、结合、重排 | 哪类用户/场景/时段被放弃了？触点顺序能否调换？服务能否与用户已有动作合并？ | 只说"提升服务态度/加强培训" |
| 内部流程 | 删除、重排、替代 | 哪些审批/等待/交接可以删、并行或前置？哪个人工环节可以换成规则或自助？ | 把流程问题当工具问题（上系统解决制度问题） |
| 内容/课程/社群 | 修改、他用、结合 | 粒度、时长、难度能否切分？内容能否复用/切片/组合成新产品？ | 加互动=加弹幕/打卡 |

## 四、痛点类型 → 主攻维度（展开版）

SKILL.md 给的是速查版；下表补充"优先问什么"，用于展开主攻维度时。

| 痛点类型 | 主攻维度 | 优先问什么 |
|---|---|---|
| 成本高、利润薄 | 替代、删除、修改（缩小） | 哪个成本项由"习惯"而非"必要"支撑？哪个环节删掉用户不会察觉？ |
| 效率低、周期长 | 删除、重排、替代 | 哪两步在互相等待？哪个审批只是为了留痕？ |
| 体验差、投诉多 | 结合、适应、重排 | 用户在哪个触点被迫切换？哪一步在替公司省事、给用户添麻烦？ |
| 同质化、没差异 | 结合、他用、逆向 | 我们能做但对手做不了的是什么？行业默认做法如果反过来会怎样？ |
| 增长停滞、有天花板 | 他用、结合、修改（放大） | 现有能力还能服务谁？哪一段可以单独卖？ |
| 质量不稳、强依赖人 | 替代、适应、修改（标准化） | 哪一步的结果取决于某个人当天状态？能否变成清单或规则？ |
| 收入单一、依赖大客户 | 他用、结合、逆向（谁付费） | 除了现在的付费方，还有谁因结果受益？能否让他付费？ |

## 五、七维检核表

### 1. 替代（Substitute）

- **核心思想**：用新元素替换现有部分，通过替换带来改进或创新。
- **思考方向**：材料/技术/组件替代；流程/人员替代（含自动化）；感官与交互方式替代。
- **引导问题**：哪个部分最可被替代？替代后带来什么具体好处？市场上有哪些现成替代方案？
- **实例**：白炽灯 → LED；人工客服部分环节 → 自助与知识库。
- **合格创意示例**：`S1 把"人工答疑"替换为"往期学员卡点录屏"`——同类人的解法更容易被采纳（功能｜改良）。

### 2. 结合（Combine）

- **核心思想**：把不同元素、功能、场景结合，创造新价值或解决现有问题。
- **思考方向**：功能合并；服务与场景整合；技术与需求组合；与用户已有动作合并。
- **引导问题**：可以和什么结合创造新价值？结合后解决了什么新问题？是否会增加使用复杂度？
- **实例**：智能手机合并电话/相机/音乐/导航；咖啡 + 书店。
- **合格创意示例**：`C1 作业自动生成周报图表`——学习成果直接进入工作产出（商业｜改良）。

### 3. 适应（Adapt）

- **核心思想**：调整自己以适配新环境、新人群、新规则。
- **思考方向**：场景/人群适应；地域/法规/文化适应；技术与渠道适应。
- **引导问题**：目前在哪些场景或人群上表现不佳？需要保住的核心价值是什么？
- **实例**：手机防水；软件本地化适配各国法规。
- **合格创意示例**：`A1 为通勤场景做 8 分钟音频版`——把开始门槛从"整块时间"降到"碎片时间"（功能｜改良）。

### 4. 修改/放大/缩小（Modify / Magnify / Minify）

- **核心思想**：改变规格、强度、粒度、频率、时长，创造新可能。
- **思考方向**：尺寸/外观；功能强弱；时间与成本；信息密度。
- **引导问题**：哪个规格最影响用户行为？放大或缩小之后谁会受益？
- **实例**：大屏手机；快递次日达 → 当日达。
- **合格创意示例**：`M1 60 分钟课切 6 个 10 分钟单元`——单次启动成本降低（功能｜改良）。

### 5. 用于其它用途（Put to other purposes）

- **核心思想**：跳出原始设计用途，寻找新场景、新用户、新收入。
- **思考方向**：跨行业/跨场景；能力复用与技术迁移；用户群扩展与资产再利用。
- **引导问题**：这套能力还能解决谁的什么问题？需要做什么最小改动才能复用？
- **实例**：小苏打从烘焙扩展到清洁除臭；游戏引擎用于影视特效。
- **合格创意示例**：`P1 把课程模板单独卖给不买课的企业`——同一资产第二条收入线（商业｜重构）。

### 6. 删除（Eliminate）

- **核心思想**：移除不产生价值的部分，简化、降本、聚焦。
- **思考方向**：功能/元素；流程/字段/信息；等待时间与隐性成本。
- **引导问题**：哪一步删掉后用户反而更愿意用？删掉会失去谁？如何补偿？
- **实例**：手机去掉实体键盘；超市自助收银减少人工台。
- **合格创意示例**：`E2 删除结业考试，改为每单元通过即解锁`——奖励周期从 12 周缩到 1 周（流程｜改良）。

### 7. 重新安排/逆向（Rearrange / Reverse）

- **核心思想**：改变顺序、结构、角色分工，或从相反角度思考。
- **思考方向**：顺序/布局/时间重排；角色与责任重排；因果逆向、付费方逆向。
- **引导问题**：哪个顺序倒过来更快？如果这个环节完全不做会怎样？谁付钱、谁使用可以换吗？
- **实例**：洗衣机从顶开盖到前开门；从"如何提升销售额"逆转为"如何减少客户流失"。
- **合格创意示例**：`R1 先给做不出来的真实任务，再按卡点推章节`——从被动听课变成带着问题找答案（流程｜重构）。

## 六、低产维度说明模板

某维度确实只能出 1 条时，按此写一行，禁止硬凑：

```
【维度】本次仅 1 条：<创意>。该维度对本对象价值低，原因是 <对象是流程型/核心约束在手感而非规格/…>。
```

## 七、跨维度组合模板

组合的价值来自"两个维度同时改，产生单一维度做不到的效果"。

| 组合编号 | 涉及维度 | 组合方案（一句话） | 产生的独特价值 | 实施难度 |
|---|---|---|---|---|
| X1 | 修改 + 删除 | 单元切分 + 完成即解锁 | 每次投入变小，流失可提前发现 | 低 |
| X2 | 结合 + 他用 | 作业即产出 + 模板外售 | 学习成果变工作成果，同时打开企业客户 | 中 |

填写要求：

- 每组必须写"为什么单一维度做不到"，写不出就说明只是两件事的拼盘。
- 组合编号独立于七维编号，不混用。
