# 与其他分析工具的衔接

> 安索夫矩阵负责"选增长方向"，其他工具负责提供输入或承接输出。不要在一次回答里把所有工具都跑一遍。

## 一、前置工具：输出如何指向象限

| 工具 | 关键输出 | 对安索夫分析的指向 |
|---|---|---|
| PEST | 政策、经济、社会、技术趋势 | 政策/合规 → 市场开发的准入判断；经济 → 渗透的消费力；社会 → 延伸的需求变化；技术 → 多样化的可行性 |
| 波特五力 | 竞争强度、进入壁垒、替代品、议价能力 | 竞争激烈 → 优先产品延伸做差异化；新进入者多 → 加强渗透建壁垒；替代品强 → 考虑多样化；买方强势 → 市场开发找新客群 |
| SWOT | 优势、劣势、机会、威胁 | 优势 → 可支撑的象限；劣势 → 限制的象限；机会 → 指向的象限；威胁 → 必须应对的象限 |
| BCG 矩阵 | 产品的明星/现金牛/问题/瘦狗定位 | 明星 → 渗透/开发；现金牛 → 渗透维持 + 延伸；问题 → 开发验证或延伸；瘦狗 → 退出或多样化转型 |

**使用规则**：只选与当前问题最相关的 1-2 个前置工具，且只提取与象限判断有关的结论，不做完整工具报告。

## 二、后置工具：承接策略落地

| 工具 | 承接内容 |
|---|---|
| 财务测算 | 各象限的投入需求、收入增量、回收期与 ROI；无数据时给出测算口径与假设 |
| 项目计划 | 把 90 天路线图拆成里程碑、负责人角色与交付物 |
| KPI 体系 | 为每个象限设定 2-3 个领先指标 + 1 个结果指标，并设预警线 |

## 三、三档分析深度

| 档位 | 工具组合 | 适用场景 | 对应输出模式 |
|---|---|---|---|
| 轻量 | 企业画像 + 安索夫矩阵 + 加权评分 | 中小企业快速决策、单点问题 | 快速决策卡 / 标准方案 |
| 标准 | PEST 或五力（择一）+ SWOT + 安索夫矩阵 + 评分 | 年度增长规划、进入新市场 | 标准方案 |
| 深度 | 全套前置工具 + 财务测算 + 情景规划 | 重大转型、重大投入 | 深度方案 |

**原则**：工具越多不等于结论越准。缺少数据时，增加工具只会增加假设数量。

## 四、外部数据核验清单

| 数据类型 | 来源要求 | 处理方式 |
|---|---|---|
| 企业自身数据（营收、客户数、流失率、毛利） | 必须由用户提供 | 未提供时按规模分档假设，并标注"假设（待验证）" |
| 行业规模、增速、集中度 | 需公开来源或用户提供 | 不凭记忆给具体数字；无来源时只做定性判断 |
| 竞品份额、价格、渠道 | 需用户提供或可查证 | 未核实的竞品信息不得作为评分主要依据 |
| 政策、资质、合规要求 | 需查证官方口径 | 明确提示以主管部门最新规定为准 |
| 消费者偏好、区域差异 | 用户经验或调研数据 | 标注为经验判断，并给出验证方式 |

**硬性要求**：
1. 不编造市场规模、增长率、竞品份额等具体数字。
2. 所有假设集中列在报告"假设与数据来源"栏，不能散落在正文中伪装成事实。
3. 需要外部事实时，说明"建议通过什么方式核实"，而不是直接给结论。
4. 涉及医疗、金融、法律等强监管业务，补充一句"需专业机构复核"的合规提示。
