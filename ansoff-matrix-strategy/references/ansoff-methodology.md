# 安索夫矩阵方法论

> 本文件只提供方法细节，不定义对话流程；流程以 SKILL.md 为准。

## 一、模型结构

| | 现有产品 | 新产品 |
|---|---|---|
| **现有市场** | 市场渗透（低风险） | 产品延伸（中高风险） |
| **新市场** | 市场开发（中风险） | 经营多样化（高风险） |

- 横轴（产品维度）：现有产品 → 新产品（需要开发或引入的产品/服务）
- 纵轴（市场维度）：现有市场 → 新市场（新客群、新区域、新渠道）
- **"新"的判定标准**：对企业而言是否需要新建能力或新增投入。
  - 同一客群换触达方式（如线下转线上自营），若运营能力可复用，仍按"现有市场"处理；
  - 若新渠道需要独立团队、独立供应链或独立合规资质，则按"新市场"处理，并在分析中说明理由。

## 二、风险梯度

| 策略 | 风险等级 | 核心原因 |
|---|---|---|
| 市场渗透 | 低 | 熟悉的市场 + 熟悉的产品，不确定性最小 |
| 市场开发 | 中 | 产品已验证，但市场环境、渠道与合规存在不确定性 |
| 产品延伸 | 中高 | 市场已熟悉，但新产品存在研发、供应链与品牌适配风险 |
| 经营多样化 | 高 | 产品与市场双重不确定，且协同效应需要额外建设 |

**风险递增规律**：向右增加产品风险，向上增加市场不确定性，对角线移动承担双重风险。

**选择原则**：
- 资源有限时优先低风险象限；
- 增长缺口大时可承担中风险，但必须有止损点；
- 多样化只在主业现金流安全、且存在可迁移核心能力时启动。

## 三、四象限详解

### 1. 市场渗透（现有产品 + 现有市场）

**定义**：在现有市场提高现有产品的份额、使用深度与购买频次。

**适用信号**：市场仍处成长期或成熟期早期；品牌已有认知；产能/资源未充分利用；竞争对手份额可被蚕食。

**深度应用方法**：
- 密度渗透：优化渠道/门店布局，提高覆盖与触达
- 频次提升：会员体系、订阅、复购激励
- 份额争夺：针对性营销，从竞对获取客户
- 价格与结构优化：基于数据的定价、套餐与搭售
- 场景拓展：开发新的使用场景，提升单客消费

**量化抓手**：用"增长公式"定位最弱变量（见第四节），只打最短板，不同时做四件事。

**风险与应对**：市场饱和（监测渗透率）、价格战（强调差异化价值）、边际效益递减（盯投入产出比，及时切换象限）。

### 2. 市场开发（现有产品 + 新市场）

**定义**：把已验证的产品引入新区域、新渠道或新客群。

**适用信号**：产品在现有市场已验证；新产品开发成本高；目标市场需求特征相似；具备跨区域/跨渠道运营能力。

**深度应用方法**：
- 地域扩张：下沉市场、海外市场、跨区域复制
- 渠道创新：线上线下融合、社交电商、社区/即时零售
- 客群延展：从 C 端到 B 端，或从一类人群到相邻人群
- 商业模式平移：在原有能力上增加新的交易方式
- 本地化调整：按目标市场调整产品呈现、定价与服务

**量化抓手**：用"市场筛选漏斗"排序候选市场（见第五节），先做 1 个试点市场，不并线铺开。

**风险与应对**：文化/习惯不适配（先小规模验证）、渠道冲突（设计渠道政策）、资源分散（聚焦单点）。

### 3. 产品延伸（新产品 + 现有市场）

**定义**：面向现有客群开发或引入新产品/新服务，提升单客价值。

**适用信号**：现有客群有未被满足的相关需求；具备开发或供应链资源；品牌在现有市场有信任度；获客成本高、需要深挖存量。

**深度应用方法**：
- 垂直延伸：同品类的高/中/低端覆盖
- 横向延伸：互补产品与服务
- 场景延伸：围绕客户使用场景做配套
- 服务升级：在产品上叠加增值服务
- 数字化延伸：工具、内容、会员权益等数字产品

**量化抓手**：用"相邻性判定"打分（见第六节），优先强相邻产品。

**风险与应对**：品牌稀释（守住核心价值）、内部竞争（明确产品定位与价格带）、资源失衡（设定新产品投入上限）。

### 4. 经营多样化（新产品 + 新市场）

**定义**：进入全新产品与全新市场的组合领域。

**适用信号**：主业增长空间有限或面临衰退；存在可迁移的核心能力；新领域前景明确；具备承担高风险的资金与组织能力。

**深度应用方法**：
- 相关多样化：基于现有技术、供应链、客群或渠道延伸
- 非相关多样化：跨领域布局，原则上不作为中小企业的首选
- 战略联盟：借合作方获取关键资源，降低试错成本
- 内部孵化：小团队、独立核算、分阶段投入
- 并购整合：用资本换时间，但需具备整合能力

**量化抓手**：先明确"新业务多久能自负盈亏"，并设定投入上限（不超过可承受亏损额度）。

**风险与应对**：管理复杂度上升（独立团队与治理）、资源过度分散（限制方向数量）、协同不足（先设计协同机制再投入）。

## 四、增长公式与变量拆解

用于把"增长"从口号变成可计算的变量，尤其服务于市场渗透。

```
营收 = 客户数 × 年均购买频次 × 客单价
客户数 = 触达量 × 转化率 ×（1 - 流失率）
```

渗透的四条路径与对应变量：

| 路径 | 作用变量 | 典型动作 | 先决条件 |
|---|---|---|---|
| 扩触达 | 触达量 | 渠道加密、投放、异业合作 | 转化率不明显低于行业 |
| 提转化 | 转化率 | 卖点重构、价格结构、体验优化 | 有稳定流量基础 |
| 提频次 | 购买频次 | 场景设计、会员、复购激励 | 产品有复购属性 |
| 提客单 | 客单价 | 套餐、搭售、升级款 | 客户信任度足够 |

**使用规则**：先估算各变量的基线，选出与目标差距最大的 1-2 个变量，避免"四条路径全做"。

## 五、市场开发的市场筛选漏斗

对候选新市场按以下 5 关逐层筛选，输出排序与首选市场：

| 关卡 | 关键问题 | 判断参考 |
|---|---|---|
| 1 需求相似度 | 目标市场是否在解决同一类任务/需求？ | 核心需求可复用比例高 → 优先 |
| 2 市场容量 | 目标市场规模与增长是否能支撑目标增量？ | 无可靠数据时标注"假设（待验证）" |
| 3 进入壁垒 | 渠道、资质、供应链、本地关系是否可控？ | 壁垒越高，越需要合作而非自建 |
| 4 可复制性 | 产品、团队、流程迁移成本多大？ | 迁移成本 > 首年预期毛利 → 暂缓 |
| 5 合规与地缘 | 是否存在牌照、数据、税务、文化风险？ | 硬性合规不满足 → 直接排除 |

**输出要求**：给出 2-3 个候选市场排序、1 个首选试点市场、1 个 90 天验证方式（单城市/单渠道/小批量）。

## 六、产品延伸的相邻性判定

对备选新产品按 4 个维度打分（0 = 全新，1 = 部分复用，2 = 完全复用）：

| 维度 | 判定问题 |
|---|---|
| 技术/研发 | 是否能复用现有技术、配方、工艺或内容生产能力？ |
| 供应链 | 是否能复用现有采购、生产、仓储与履约？ |
| 品牌 | 新产品是否符合现有品牌定位与信任基础？ |
| 客群 | 是否面向同一批客户，或高度重叠的相邻客群？ |

**解读**：总分 6-8 分为强相邻（成功率高，可优先）；3-5 分为中等相邻（需试点）；0-2 分实质已是多样化，应按高风险策略对待。

## 七、多样化的进入方式选择

| 方式 | 适用条件 | 主要代价 |
|---|---|---|
| 自建 | 核心能力可复用、节奏可控、试错成本低 | 慢，可能错过窗口 |
| 并购 | 时间窗口紧、需要牌照/客户/技术、具备整合能力 | 贵，整合风险高 |
| 联盟/合资 | 关键资源缺失、不确定性高、想先学习 | 控制力弱，利益分配复杂 |

## 八、象限迁移条件

| 迁移 | 触发信号（示例阈值，按企业规模调整） |
|---|---|
| 渗透 → 市场开发 | 核心区域覆盖率接近上限；获客成本连续两个季度上升超过 30%；客单价提升空间不足 10% |
| 市场开发 → 产品延伸 | 试点市场 3 个月单位经济为正；同一客群重复提出同类新需求且占比超过 30% |
| 产品延伸 → 多样化 | 主业增速低于行业平均；现金可覆盖 12 个月固定支出；存在可迁移的核心能力 |
| 任意象限 → 降级/退出 | 连续两个复盘周期里程碑达成率低于 60%，或单位经济持续为负且无改善路径 |

## 九、常见误区

**策略制定阶段**
1. 过度依赖单一象限，忽视组合与协同
2. 选择超出资源与能力范围的策略
3. 策略与能力错配（无研发能力却主攻产品延伸）
4. 没有失败预案与止损点
5. 目标过于激进，缺少阶段性验证

**策略执行阶段**
1. 策略摇摆，资源分散
2. 不调整组织与考核，新策略沿用旧机制
3. 缺少数据监测，问题发现太晚
4. 不根据市场反馈修正策略
5. 团队能力不足，未做培训或引才

**分析阶段**
6. 把行业标签当成结论，用"行业惯例"替代企业画像
7. 用模糊形容词代替数字，导致方案无法验收
8. 只给"做什么"，不给"不做什么"
