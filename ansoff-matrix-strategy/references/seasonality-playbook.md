# 淡旺季平衡专项

> 适用于餐饮、文旅、零售、教育、农业、服装等季节性业务。淡旺季不是独立策略，而是叠加在安索夫四象限上的约束与杠杆。

## 一、季节性诊断

### 波动系数

```
波动系数 = 旺季月均营收 / 淡季月均营收
淡季收入占比 = 淡季月份营收合计 / 全年营收
```

| 波动系数 | 判定 | 策略含义 |
|---|---|---|
| > 2.0 | 高波动 | 必须做结构性对冲，否则旺季利润被淡季亏损吞掉 |
| 1.5-2.0 | 中等波动 | 优先做现金流平滑与淡季填充 |
| < 1.5 | 低波动 | 淡旺季不是主要矛盾，按常规四象限分析即可 |

### 淡季成因分类

| 类型 | 典型表现 | 诊断问题 |
|---|---|---|
| 需求型 | 气候、节假日、消费习惯导致客流下降 | 客户"不想来"还是"来不了"？ |
| 供给型 | 原料、产能、人力存在季节性约束 | 淡季是没客人，还是接不了客？ |
| 渠道型 | 平台流量周期、B 端预算周期 | 淡季是全域下降，还是某一渠道下降？ |
| 政策型 | 学期制、财政预算、法规窗口 | 淡季是否由外部制度决定、不可改变？ |

诊断结论要落到"哪一类为主"，因为四类成因对应的杠杆不同：需求型靠产品与客群，供给型靠产能与用工，渠道型靠渠道组合，政策型靠 B 端与预售。

## 二、四类平衡杠杆

### 1. 产品组合季节互补

- 用反季产品填谷：如火锅店增加冷饮/烧烤/轻食，滑雪场增加山地度假/研学
- 主副业互补：淡季主推低成本、低客单的引流产品，旺季主推高毛利产品
- 注意：新产品应尽量复用现有供应链与门店/渠道，避免为淡季单独建一套能力

### 2. 客群结构对冲

- C 端转 B 端：企业团建、员工福利、团餐、企业培训、会议接待
- 机构客户：学校、旅行社、社区、异业联盟
- 判断标准：B 端订单是否能在淡季提前锁定，且毛利不低于 C 端

### 3. 渠道与地域对冲

- 渠道：线下淡季时加大线上/外卖/直播/私域的比重
- 地域：南北半球反季、南方避暑与北方避寒、城市与县域互补
- 注意：跨地域扩张应按"市场开发"策略评估，不能只当作淡季补丁

### 4. 现金流平滑

- 年卡/季卡/订阅制，把收入前置
- 预售与储值，但需控制履约风险与退款风险
- 淡季打包套餐、阶梯定价（旺季溢价、淡季折扣）
- 成本侧：弹性用工、设备租赁、淡季集中做维护/培训/研发

## 三、四象限 × 淡旺季动作表

| 时段 | 主动作 | 辅动作 | 禁止动作 |
|---|---|---|---|
| 旺季 | 市场渗透：提价、加 SKU、抢份额、锁客会员 | 市场开发：新客群小规模试点 | 大面积开新店/重投新业务 |
| 淡季 | 市场开发：新区域、新客群、新渠道 | 产品延伸：低成本试点反季产品；渗透：预售与会员 | 用降价换量、透支品牌 |
| 全年 | 产品延伸在淡季验证、旺季放量 | 多样化仅在现金可覆盖 12 个月时启动 | 用旺季利润补贴无止损的新业务 |

**核心原则**：旺季赚利润与现金流，淡季做验证与结构优化；反季扩张必须设止损点。

## 四、淡旺季专属 KPI

| 指标 | 定义 | 用途 |
|---|---|---|
| 淡季收入占比 | 淡季营收 / 全年营收 | 衡量结构平衡进度 |
| 波动系数 | 旺季月均 / 淡季月均 | 衡量季节性风险 |
| 淡季毛利率 | 淡季毛利 / 淡季营收 | 防止"有收入没利润" |
| 现金覆盖月数 | 现金 / 月均固定支出 | 判断能否扛过淡季 |
| 淡季获客成本 | 淡季获客投入 / 淡季新增客户 | 判断淡季投放是否值得 |
| 预售/会员收入占比 | 预收+会员收入 / 总营收 | 衡量现金流前置能力 |
| 旺季产能利用率 | 实际接待量 / 最大接待量 | 判断旺季是否还有渗透空间 |

## 五、行业示意（不提供具体市场数据）

### 餐饮（火锅/烧烤等夏季淡季）

- 诊断：需求型为主，叠加渠道型（外卖占比低）
- 杠杆：反季产品（冷饮/轻食/烧烤）、外卖与零售化、企业团餐、淡季套餐
- KPI：淡季桌均、外卖占比、淡季毛利率
- 风险：为淡季新增过多 SKU 导致备货与损耗上升

### 文旅（冬季或雨季淡季）

- 诊断：需求型 + 政策型（假期制度）
- 杠杆：温泉/研学/会议接待、年卡与预售、工作日填充、跨区域客源
- KPI：淡季入住率、客单价、现金覆盖月数
- 风险：淡季降价损伤旺季价格锚

### 教育培训（学期制淡季）

- 诊断：政策型为主
- 杠杆：寒暑假营地、成人技能课、企业培训、线上课程
- KPI：淡季班均人数、B 端收入占比、续费率
- 风险：B 端项目制收入波动更大，需控制账期
