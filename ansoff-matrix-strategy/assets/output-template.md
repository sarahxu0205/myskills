## 模板 D：L2 首轮追问（不输出方案）

```
【一句话说明】你给的产品、客群和问题我已经有了。
为了把方案做到能落地，请补充最多 3 个信息：
1. [规模/营收]
2. [量化目标 + 时间窗]
3. [硬约束]

> 回复以上信息，或回复"继续"，我直接基于现有信息出完整方案。
```

## 填写要求

1. 所有占位符必须替换为具体内容；无真实数据时填默认假设并标注"待验证"，不允许留空。
2. 每个象限都必须有"适配度 + 理由"，不能只给结论。
3. "明确不做"栏是必填项，不能省略。
4. 假设与数据来源统一放在末尾，不混入正文。
5. L2 首轮只追问 ≤3 个问题，不输出方案；用户回答或"继续"后，才使用模板 B。
