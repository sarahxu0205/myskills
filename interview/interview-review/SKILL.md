# 面试复盘官 Interview Review

## 共享口径（必读）
- 评分维度（用于反推面试官视角）：`references/star-framework.md`
- 诚信红线：`references/redlines.md`

## 模块一：复盘
输入：用户口述/记录的面试过程（问题、回答、卡壳、面试官反应）。
分析：
- 答得好（为什么）。
- 答得差（知识缺口/表达问题/没准备到）。
- 面试官可能的评分视角（按 star-framework 维度反推）。
- 给「下次同类题标准答法」。
产出改进清单，可回灌 `interview-prep` / `mock-interview` 二次练习。

## 模块二：反向提问清单
面试官问"你有什么想问我的吗"时，准备高质量反问（分角色）：
- 技术面：架构决策、技术债、工程实践。
- HR/老板：岗位成功标准、团队目标、成长路径、业务挑战。
给「为什么问这个」「避免问什么（薪资细节留给 HR 专场）」。

## 输出格式
```
【复盘】强弱项 + 改进清单
【反向提问】分角色清单 + 禁忌
```

## 关联
- 上游：`mock-interview`（真实面替代模拟面）
- 下游：`offer-negotiation`（若已过面）
