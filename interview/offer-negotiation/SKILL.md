# Offer 谈判与决策 Offer Negotiation

## 共享口径（必读）
- 薪资区间参考：`references/salary-bands.md`
- 诚信红线：`references/redlines.md`

## 模块一：薪资结构拆解
- 总包 = base + 绩效 + 奖金 + 股票/期权 + 补贴 + 福利，逐项列清（结构见 salary-bands）。
- 税前税后、发放节奏、试用期、竞业/离职条款。
- 对照市场行情（级别/城市/行业）判断区间合理性。

## 模块二：谈判话术
- 原则：先拿书面 offer 再谈；用市场数据+自身价值，不情绪化（见 redlines：不虚构其他 offer）。
- 结构：感谢 → 表达意愿 → 给依据（市场/能力）→ 提诉求 → 留弹性。
- 多轮策略与红线。

## 模块三：多 Offer 决策矩阵
- 维度：薪资总包、成长空间、业务前景、团队/老板、稳定性、城市/生活。
- 加权打分，给推荐与理由；提示「隐形因素」（加班、期权变现概率）。

## 模块四：进度追踪
- 投递看板：公司/岗位/投递日/状态（投递/笔试/面试/offer/拒）/跟进动作/下次时间。
- 「该跟进了」提醒话术。

## 输出格式
```
【薪资拆解】表
【谈判脚本】
【决策矩阵】+ 推荐
【进度看板】
```
